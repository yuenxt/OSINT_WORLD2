# OSINT WORLD — clean Android project

Это полностью новый минимальный Kivy-проект без сторонних Python-библиотек кроме Kivy.
Все функции внутри — игровая симуляция. Реальный поиск людей, взлом аккаунтов и реальные удаления данных не выполняются.

Сборка:
1. GitHub Actions -> Build OSINT WORLD APK -> Run workflow.
2. После успешной сборки открыть Artifacts.
3. Скачать OSINT_WORLD_APK.

Buildozer использует стандартную Android-сборку debug.
